# 💻 Meu Portfólio Profissional - Web Developer

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para consolidar minha presença digital, apresentar meus principais projetos e demonstrar minhas habilidades técnicas como desenvolvedor em transição de carreira para o setor de Tecnologia da Informação.

O site foi construído com foco em alta performance, componentização limpa e um design moderno utilizando CSS estruturado de forma global.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando o ecossistema moderno do ecossistema JavaScript:

* **React.js** – Biblioteca para construção da interface baseada em componentes reaproveitáveis.
* **Vite** – Bundler de última geração que proporciona um ambiente de desenvolvimento ultra rápido.
* **JavaScript (ES6+)** – Lógica de renderização de dados dinâmica e manipulação de estado.
* **CSS3 Global** – Estilização centralizada com variáveis nativas (`:root`), animações personalizadas e total responsividade (Mobile First).
* **HTML5 Semântico** – Estruturação focada em acessibilidade e boas práticas de SEO.

---

## 🎨 Funcionalidades Principais

* **Arquitetura Orquestrada:** Separação rígida de responsabilidades, dividindo o layout entre seções (`Hero`, `About`, `Skills`, `Projects`, `Contact`) e subcomponentes reutilizáveis (`ProjectCard`, `SkillCard`).
* **Efeito Hover Dinâmico:** Cards da seção "Sobre mim" que utilizam variáveis CSS dinâmicas (`--card-theme`) para criar bordas finas iluminadas e sombreados sutis ao passar o mouse.
* **Navegação Inteligente:** Navbar com detector de rolagem (`window.scrollY`) que ativa dinamicamente o link da seção onde o usuário está navegando.
* **Rolagem Suave:** Navegação interna guiada por funções JavaScript de scroll personalizado sem a necessidade de bibliotecas externas pesadas.
* **Suporte a SVGs Inline:** Ícones sociais e do ecossistema otimizados para carregamento instantâneo.

## 📂 Estrutura do Projeto

Abaixo está uma visão simplificada de como organizei as pastas para manter o código limpo:

```text
src/
├── components/          # Subcomponentes reaproveitáveis (Cards, Navbar, Footer)
│   └── Icons/           # Ícones em formato SVG
├── data/                # Arquivos de dados estáticos para fácil manutenção de textos
├── sections/            # Grandes blocos de seções da página única (Hero, About, etc.)
├── styles/
│   └── global.css       # Toda a folha de estilo, variáveis e media queries do projeto
├── App.jsx              # Componente orquestrador principal do portfólio
└── main.jsx             # Ponto de entrada do React no ecossistema Vite
```
